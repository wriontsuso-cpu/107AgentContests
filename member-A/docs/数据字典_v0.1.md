# 数据字典 v0.1

> 成员 A 提供 · 供成员 B（AI/后端）、C（前端）、D（集成）对接  
> 版本：2026-08-20 · 对应数据库 schema v0.1

---

## 1. 资源实体 `Resource`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string (UUID) | 是 | 稳定主键，由 URL 生成，不随标题变化 |
| `title` | string | 是 | 资源名称，4–200 字 |
| `summary` | string | 否 | 一句话简介，建议 ≤200 字，检索与卡片展示用 |
| `url` | string | 是 | 官方链接；`mailto:` 不入库 |
| `category_id` | string | 是 | 关联 `categories.id`（分类树 v1） |
| `category_path` | string | 导出 | 如 `全部资源/发展机会/留学与出境交流` |
| `category_name` | string | 导出 | 叶子分类名 |
| `legacy_category` | string | 否 | 原始爬虫栏目，便于溯源 |
| `tags` | string[] | 否 | 多标签，如 `免费`、`二课`、`留学` |
| `source_type` | enum | 是 | `crawl` / `curated` / `questionnaire` / `interview` |
| `source_name` | string | 否 | 如 `学工在线-奖助学金` |
| `access_type` | enum | 是 | `public` / `login_required` / `external` |
| `cost` | string | 否 | 费用说明，如 `免费（需学生认证）` |
| `how_to` | string | 否 | 获取或使用方式 |
| `published_at` | string | 否 | 原文发布日期 |
| `updated_at` | string | 是 | ISO8601，最后入库/更新时间 |
| `relevance_score` | int | 否 | 学生相关度，0–10 |
| `kind` | string | 否 | `curated` / `crawl` |
| `status` | enum | 是 | `active` / `deprecated` |

### `access_type` 说明

| 值 | 含义 |
|----|------|
| `public` | 无需登录即可访问的公开页 |
| `login_required` | 链接公开，但内容/功能需统一认证 |
| `external` | 校外站点（GitHub、JetBrains 等） |

## 2. 分类 `Category`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 如 `opportunity_abroad` |
| `parent_id` | string \| null | 父节点 id，`root` 的子节点 parent 为 `root` |
| `name` | string | 显示名称 |
| `level` | int | 0=根，1=一级，2=二级 |
| `path` | string | 完整路径，用 `/` 分隔 |
| `sort_order` | int | 同级排序 |
| `children` | Category[] | 导出树时嵌套 |

分类树定义文件：`data/categories_v1.json`

---

## 3. 标签 `Tag`

- 字符串，唯一
- 通过 `resource_tags` 与资源多对多关联
- 全量列表见导出：`data/export/taxonomy.json` → `tags`

---

## 4. 文件与路径约定

| 用途 | 路径 |
|------|------|
| SQLite 数据库 | `db/ustc_resources.db` |
| 分类树 | `data/categories_v1.json` |
| 栏目映射 | `data/category_mapping.json` |
| 数据版本 | `data/VERSION` |
| B 向量/检索用 | `data/export/resources.jsonl` |
| C 联调 Mock | `mock/resources.json`、`mock/categories.json` |
| 全量 API JSON | `data/export/resources.json` |
| 分类+标签 | `data/export/taxonomy.json` |

## 5. 更新流程（D 集成用）

```powershell
cd ustc-crawler
py main.py --full --no-body          # 1. 采集
py scripts/import_json.py            # 2. 入库
py scripts/export_api.py             # 3. 导出给 B/C
py export_backup.py                  # 4. 可选：文档备份
```

版本号写入 `data/VERSION`，格式：`YYYY-MM-DD-r{采集数}-db{库内条数}`

## 6. 给成员 B 的检索建议

- **主键检索**：`id`
- **关键词**：`title` + `summary` + `tags`
- **过滤**：`access_type=public` 优先展示；`login_required` 标注「需登录」
- **JSONL 每行一条**，字段见第 1 节

---

## 7. 给成员 C 的前端建议

- 树状浏览：读 `mock/categories.json` → `tree`
- 列表/详情：读 `mock/resources.json` → `resources[]`
- 节点点击：按 `category_id` 过滤同分类资源
- 详情页展示：`title, summary, url, tags, cost, how_to, access_type`
