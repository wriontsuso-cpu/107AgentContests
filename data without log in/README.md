## 三、数据组成与去重策略

- **组成**：非登录 627 + mine 783 + 扩展采集（图书馆资源 / 青春科大 / 二课团学活动 / 教务服务 / 国合部新闻 / 研招 / vlab / 就业指导 / 研究生院 / 瀚海星云等）+ 门户学术报告 2802 + 登录态门户内网采集（通知公告 4189 / 校园资讯 1500 / 学术讲座 643 / 服务导航 186），去重后共 10836 条。
- **去重策略**：先按 URL 归一化去重（统一 http/https、去锚点、去末尾斜杠），再按「标题指纹」内容级去重——同一讯息来自不同网址合并为一条，权威保序 校级 > 职能部门 > 部门/服务 > 学生自建/聚合；短标题（导航/入口类）不参与内容合并。
- **内网边界（合规）**：登录态采集仅用「本人账号登录后可见的公开/指导型内容」（通知公告、校园资讯、学术讲座、服务导航、办事指南）；不采集成绩、选课结果、课表、消费流水、体检、资助申请、个人日程/待办/邮箱等个人数据；教务系统 `jw.ustc.edu.cn` 个人记录已按合规边界排除；Cookie 文件不提交 git，任务完成后可删除。
